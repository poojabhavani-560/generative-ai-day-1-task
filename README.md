# Generative AI - Prompt Engineering Basics

## Day 1: Introduction to Prompt Engineering

This repository marks the beginning of my journey into Generative AI and Prompt Engineering. The goal is to understand how to interact effectively with AI models like ChatGPT to generate accurate and useful outputs.

---

## What is a Prompt?

A prompt is a piece of text or instruction given to an AI model to generate a response. It acts as the input that guides the AI’s output.

A well-structured prompt helps in getting more accurate, relevant, and high-quality responses.

---

## Types of Prompts

### 1. Simple Prompt
A basic instruction without much detail.

**Example:**
Explain Artificial Intelligence.

---

### 2. Detailed Prompt
A more specific instruction with clarity and context.

**Example:**
Explain Artificial Intelligence in simple terms with real-life examples for beginners.

---

## My Practice

### Prompt 1:
Explain Python in simple terms.

### Output:
Python is a simple and easy-to-learn programming language used to create software, websites, and applications. It has a clear syntax, which makes it beginner-friendly. Python is widely used in fields like web development, data science, artificial intelligence, and automation.

---

### Prompt 2:
Write a short paragraph about climate change.

### Output:
Climate change refers to long-term changes in temperature and weather patterns, mainly caused by human activities like burning fossil fuels and deforestation. It leads to global warming, rising sea levels, and extreme weather conditions. Addressing climate change requires collective efforts such as reducing carbon emissions and adopting sustainable practices.

---

### Prompt 3:
Give 5 uses of Artificial Intelligence in daily life.

### Output:
1. Voice assistants like Alexa and Siri  
2. Recommendation systems on Netflix and YouTube  
3. Navigation apps like Google Maps  
4. Spam email filtering  
5. Chatbots for customer support

## Key Learnings

- Clear and detailed prompts produce better results  
- Adding context improves AI understanding  
- Structured prompts help in getting accurate answers  
- Prompt engineering is an important skill in Generative AI
